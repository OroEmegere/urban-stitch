# XerXes Fits

## Project Description
A responsive fashion store website built with React JS. Visitors can browse products, search and filter them, add items to a cart, read about the brand and send a message through a validated contact form.

## Technologies Used
- React JS (Vite), JavaScript, React Router, HTML, CSS

## Features
- Home, About, Products and Contact pages using React Router
- Reusable components using props
- Cart, favourite button and search/filter using useState
- Contact form with validation
- Responsive layout for mobile, tablet and desktop

## Installation
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run: npm install
4. Start the application: npm run dev
